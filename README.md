# Pharma Market Intelligence PL

Statyczny dashboard (HTML/JS, bez serwera) rynku leków refundowanych i programów lekowych w Polsce: wykazy refundacyjne MZ (A1/B/C), zlecenia i rekomendacje AOTMiT oraz stanowiska Rady Przejrzystości, dane NFZ o refundacji i pacjentach, rejestr produktów leczniczych, przetargi.

Wersja online: https://damiangrok5-droid.github.io/pharma-market-intelligence-pl-app/

## Źródła danych
- Ministerstwo Zdrowia – obwieszczenia w sprawie wykazu leków refundowanych (gov.pl)
- AOTMiT – BIP: zlecenia MZ, rekomendacje Prezesa, stanowiska/opinie Rady Przejrzystości (bip.aotm.gov.pl)
- NFZ – statystyki i API (api.nfz.gov.pl, nfz.gov.pl)
- Rejestr Produktów Leczniczych / URPL (rejestry.ezdrowie.gov.pl)
- dane.gov.pl
- GUS – Bank Danych Lokalnych (bdl.stat.gov.pl)
- EMA (ema.europa.eu)
- TED – zamówienia publiczne UE (api.ted.europa.eu)

Każda wartość w aplikacji ma podane źródło i datę; braki oznaczono „brak danych” i opisano w zakładce „Źródła i luki”.

Dane publiczne, stan na 2026-10-25.
